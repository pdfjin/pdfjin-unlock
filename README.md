# 📄 pdfjin-unlock

> Unlock and decrypt password-protected PDFs by PDFJin by [PDFJin](https://pdfjin.com).

[![PyPI version](https://img.shields.io/pypi/v/pdfjin-unlock.svg)](https://pypi.org/project/pdfjin-unlock/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/downloads/)

Fast, private, and local document processing with zero size limits.

> 🌐 **Prefer a Web UI?** Use the free online browser tool at **[https://pdfjin.com/pages/unlock-pdf.html](https://pdfjin.com/pages/unlock-pdf.html)**.

---

## 📦 Installation

```bash
pip install pdfjin-unlock
```

Or install from source:

```bash
git clone https://github.com/pdfjin/pdfjin-unlock.git
cd pdfjin-unlock
pip install .
```

---

## 🚀 Quickstart

Run via CLI:
```bash
pdfjin-unlock --help
```

Use in Python:
```python
import pdfjin_unlock
```

## 🧪 Testing
